# AIOS BRIEF SYSTEM v1
Owner: Hassan | Projects: Wopie (WOP), Jervis (JRV)

## THE ONE RULE
The Brief Card is the source of truth. Any change - a new deadline, a
scrapped idea, a fresh reference link - goes INTO the brief. Never left
sitting in a Slack message, a WhatsApp reply, or a voice note.
If it is not in the brief, it does not exist.

## TASK ID
Format: WOP-001, JRV-001. Sequential. Never reused. Never renumbered.
The same ID appears in four places:
  1. The Google Sheet row
  2. The Slack assignment message
  3. The Google Drive folder:  /Wopie/WOP-001 - Short Title/
  4. Every file name:          WOP-001_v1.mp4 -> WOP-001_v2.mp4 -> WOP-001_FINAL.mp4

Only a file ending in _FINAL is approved. This alone kills version confusion.

## FIXED VOCABULARY (do not invent new words - the Sheet must be filterable)
PRIORITY:  P1 = today, blocks something   P2 = this week   P3 = when free
STATUS:    NOT STARTED | IN PROGRESS | DRAFT SUBMITTED | IN REVIEW |
           REVISION NEEDED | APPROVED | SCHEDULED | PUBLISHED | BLOCKED

## TEAM REPLY PROTOCOL (this is the anti-chasing mechanism)
Every assignment gets one of three reactions in Slack, no typing needed:
  eyes      = I have read this and started
  check     = draft submitted, link is in the thread
  no-entry  = blocked, and I have said why in the thread
No reaction within 2 hours of assignment = it did not land. That is the
only thing Hassan follows up on. He stops chasing work and starts
chasing silence.

PART 1 - THE BRIEF CARD  (source of truth: Google Doc or Sheet row)
================================================================

TASK ID:            WOP-000
PROJECT:            Wopie | Jervis
TITLE:              (6 words max, plain, searchable)
OWNER:              Alia | Danyal | Hassan
PRIORITY:           P1 | P2 | P3
DEADLINE:           YYYY-MM-DD (final approved file in hand)

--- WHY ---
OBJECTIVE:          What this is for in one sentence. The business reason.
AUDIENCE:           Who watches it and what they already believe.
CORE MESSAGE:       The ONE idea a viewer must walk away with. One sentence.
                    If you cannot write this, the task is not ready to assign.

--- WHAT ---
DELIVERABLE:        Reel | Static post | Carousel | Script | Thumbnail | Other
PLATFORM:           Instagram | Facebook | LinkedIn | Other
SPECS:              Ratio, resolution, duration, file format, caption burn-in y/n
CREATIVE DIRECTION: Style, tone, pacing, visual treatment. Name a reference,
                    do not describe a feeling.
SCRIPT / COPY:      Full text, or "to be written by owner and approved by Hassan"
BRAND ELEMENTS:     Logo placement, fonts, colours, end card, handle, disclaimer
REFERENCES:         Links and files. Every one labelled: "use this for pacing",
                    "use this for colour". An unlabelled reference gets ignored.
DO NOT:             The traps. Wrong tone, banned claims, competitor names,
                    music that got flagged last time.

--- DONE ---
DEFINITION OF DONE: A checklist. Every line true before submission.
                    [ ] Duration within spec
                    [ ] Captions burned in and spell-checked
                    [ ] Logo on end card
                    [ ] Core message clear in first 3 seconds
                    [ ] Exported as WOP-000_v1.mp4 into the task folder
DRAFT DUE:          YYYY-MM-DD
REVISION DUE:       YYYY-MM-DD
APPROVER:           Hassan
PUBLISHER:          Name + planned publish date
STATUS:             NOT STARTED
FINAL FILE:         (Drive link, filled at approval)
